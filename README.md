A tiny deterministic program that writes one kind, funny fortune for a houseplant on the windowsill — soon the morning sun will find its tallest leaf — into entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
